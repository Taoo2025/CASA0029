================================================================================
快速开始 - London PTAL Accessibility Map
================================================================================

【第一次启动 - 3步搞定】

1️⃣ 双击运行启动脚本
   ├─ Windows 推荐: 启动地图.bat
   └─ 高级用户: 启动地图.ps1

2️⃣ 等待服务器启动
   ├─ 您会看到一个新的 PowerShell/CMD 窗口
   ├─ 窗口标题: "London PTAL Map Server"
   ├─ 显示: "Serving ..." 和 "Press Ctrl+C to stop"
   └─ 这表示服务器已启动 ✓

3️⃣ 浏览器自动打开
   ├─ 应该显示: London Transport Resilience Model
   ├─ 如果没有自动打开，手动访问:
   │  http://localhost:8080/London_PTAL_Accessibility_Map.html
   └─ 您应该看到伦敦的地图！

【使用地图】

✓ 点击 "100m Grid" 按钮切换到网格视图
✓ 点击地图上的网格单元，会显示：
  - 两个虚线等时圈（红色=公交640m，蓝色=地铁960m）
  - 步行范围内的公交和地铁站点数
✓ 搜索路线并取消，查看影响分析
✓ 点击 PTAL 图例了解可达性等级

【常见问题快速解决】

❌ 页面显示 "Failed to fetch"
→ 快速检查:
  1. 看看服务器窗口是否显示错误消息
  2. 运行: 诊断工具.ps1
  3. 查看浏览器控制台 (F12) 获得详细错误

❌ 显示 "无法连接"
→ 确保:
  1. 运行了启动地图脚本
  2. 等待至少 5 秒
  3. 检查是否有 "Serving" 消息

❌ 地图加载但没有数据
→ 这是正常的，地图会使用本地数据
  查看浏览器控制台了解加载了什么
